# 下一轮 7 组实验方案

此文档为 2026-09-22 的历史方案；SAM3 已补齐，最新数据审计、嵌套清单和
8 组主实验/16 卡双种子方案见 [next_16](../next_16/README.md)。下文的缺标注数量是当时状态。

所有选入的图像都参与训练，不划分测试集。此目录是实验方案，尚未接入提交脚本，也未提交任务。

A 组只增加训练时长。保持原学习率衰减至 665000 次的设置，之后使用最终位置学习率；增密在 332500 次结束，不延长增密、不再次重置不透明度。这样不会把学习率变化混入训练时长对照。

B 组采用嵌套数据子集，包含原 6650 张，并按两路相机的时间顺序均匀补充。其他调度先固定为基线的绝对迭代数，以限制高斯增长。每图 100 轮的协议同时增加了数据和算力，不能将全部收益归因于图像数量。A2 与 B1 都是 1330000 次，可作相同迭代预算的对照。

本轮统一保留语义权重 3.0/0.5、频率权重 0.5、lambda_dssim 0.4；暂不混入损失函数消融。

数据审计：perspective/images 有 90360 张；sparse/0_full 注册 90360 张；sparse/0 注册 6650 张。人物 mask 和语义图均只有 6650 张。扩充前需核验逐图名称覆盖，并补齐新增最多 83710 张的两类标注；不能静默将缺失遮罩作为有效背景。

扩充前还需核验两个 COLMAP 模型中重叠相机的位姿/内参及坐标系一致性。训练应使用同一初始点云，避免混入初始化差异。全量数据约为当前 13.6 倍，当前全部预加载方式应改为有上限的缓存。

现有产物只有 PLY，没有优化器 checkpoint。方案默认同初始点云重新训练；从 PLY 初始化微调是可实现的另一个方案，但不是完整断点续训。本轮应先补 checkpoint 保存与恢复，再进行长任务。

固定同一组 100 个原视角和两档扰动位姿，离线比较渲染图、训练视角指标、高斯数量与耗时；W&B 仍只记录 loss。原视角指标衡量拟合程度，扰动视角没有 GT，不计算 PSNR。

注意：现有 training_config.sh 会根据 NUM_IMAGES 重算增密时间，不能只改 NUM_IMAGES/EPOCHS 就启动本方案。需先将 plan.json 接入运行参数和数据 manifest。
