## 当前整理原则

`experiments/configs/` 仅保留两份配置，训练图像清单位于 `experiments/manifests/`。历史实验计划和候选材料移入本地 `backups/`。精选渲染及视角清单位于 `result/renderings/`，测试文档统一位于 `result/report/`。
两次建模与动态更新的完整模型和日志已发布在 ModelScope，并仍保留原 OSS 来源：

```text
oss://fmc/beifen/data/3dgs_bushu/experiments_20260923/
oss://fmc/beifen/data/3dgs_bushu/dynamic_update/20261005_173800/
```

数据、独立子集、版本化环境及完整成果统一由 ModelScope 仓库 `JingrunDu/converter_value` 提供。备份代码仓库不等于复制这些大型材料。

## OSS

先生成带时间戳的 tar 和逐文件 SHA-256 清单，存入本地 `backups/`。
归档的是实际文件内容，Git LFS 指针文件会被拒绝；不包含 `.git`。
建议上传到OSS版本目录后验证归档的SHA-256，再决定是否更新旧代码目录。
直接覆盖旧目录会留下旧版本独有的 `data/`，不应宣称两份目录完全一致。

## GitHub

代码上传至私有仓库 `JingrunDu/IndustrialGS`。新仓库以当前工作区快照作为初始提交，避免携带旧历史中的大型模型；原仓库及其历史保留在本机。
新增二进制文件已配置LFS。提交前检查新增文件和差异，
大文件须由Git LFS处理，不能直接将备份tar放进Git仓库。
数据和环境包发布在 ModelScope，GitHub 只包含代码、文档和精选成果。
